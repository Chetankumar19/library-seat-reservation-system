# library-seat-reservation-system
REST API for managing library seat bookings with real-time availability.
Library Seat Booking API is a Spring Boot backend application that allows users to view available seats and book them without authentication.

The system manages seat availability based on time intervals and prevents double booking. It is designed to be simple, fast, and suitable for integration with frontend applications.

Key Features:
- View all seats with current availability
- Book seats for a specific time interval
- Prevent overlapping reservations
- Simple user flow (no login/signup required)
- RESTful API design

Tech Stack:
- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL

Use Cases:
- Library study seat management
- Co-working space seat booking
- Basic reservation systems
